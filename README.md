# Semantic HTML Landing Page 🌐

## About

A simple and accessible landing page built using HTML5 semantic elements. This project focuses on proper page structure, clean heading hierarchy, and web accessibility.

## Features

- Semantic HTML5 structure
- Accessible navigation
- Proper heading hierarchy
- Contact form with labels and input types
- ARIA attributes for accessibility
- Footer with μID

## Technologies Used

- HTML5
